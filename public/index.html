CLOUDFLARE SETUP

Protect the route before connecting

  1. Create a named tunnel

    In Cloudflare Zero Trust → Networks → Connectors, add a tunnel. Copy its connector token into the form.

  2. Add your hostname

    Point its published application to http://127.0.0.1:3211. Choose a hostname on your Cloudflare domain.

  3. Create an Access application

    Protect the entire hostname with a self-hosted Access application. Add a Service Auth policy for a designated service token. Copy the team domain and application AUD here.

  4. Connect an AI client

    Send Authorization: Bearer …, CF-Access-Client-Id and CF-Access-Client-Secret on each request.
