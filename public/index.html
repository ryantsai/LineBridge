閘道設定

CLOUDFLARE 設定

先設定 Access，再啟動連線

  1. 建立具名通道

    在 Cloudflare Zero Trust → Networks → Connectors 新增通道，將連接器權杖貼入左側表單。

  2. 設定主機名稱

    將 published application 指向 http://127.0.0.1:3211，選用你管理的 Cloudflare 網域。

  3. 建立 Access 應用程式

    建立 self-hosted Access 應用程式，保護整個主機名稱；新增 Service Auth 原則並指定服務權杖。將團隊網域與應用程式 AUD 填入左側。

  4. 連接 AI 用戶端

    每次請求附上 Authorization: Bearer …、CF-Access-Client-Id 及 CF-Access-Client-Secret。
