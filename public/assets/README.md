# LineBridge UI assets

- `bridge-welcome.png`: generated specifically for this project with the built-in image generator; transparent PNG, 1536 × 1024. Reference and exact prompt: `../../design/hero-prompt.md`.
- `icons/*.svg`: unmodified Phosphor Core 2.1.1 regular icons, MIT license in `icons/LICENSE`. Source: https://github.com/phosphor-icons/core.
- `fonts/noto-sans-tc.css` and `fonts/files/*.woff2`: unmodified Fontsource Variable Noto Sans TC 5.3.0, SIL Open Font License in `fonts/LICENSE`. Source: https://fontsource.org/fonts/noto-sans-tc.

All assets load locally. The UI does not contact an external font or icon CDN.
